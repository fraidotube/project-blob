PROJECT BLOB - MENU SYSTEM V1

Estrarre nella root D:\ProjectBlob\Game

Poi in Godot:
1) Project -> Project Settings -> Globals/Autoload
2) aggiungi res://scenes/ui/pause_menu.tscn come "PauseMenu"
3) abilitalo

- boot -> main menu
- Nuova partita / Opzioni / Esci
- ESC in gioco -> pausa reale
- Riprendi / Opzioni / Menu principale / Esci
- risoluzione
- finestra / borderless / fullscreen
- VSync
- limite FPS
- scala rendering 3D 50%-150%
- salvataggio user://settings.cfg
