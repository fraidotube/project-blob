V4.3.4 - CONTATORE HUM

Sostituisce SOLO:
scripts/interactables/connesi_meter.gd

Nuovi campi Inspector:
- Hum Loop Sound
- Hum Volume dB
- Hum Max Distance

IMPORTANTE:
Il file assegnato a Hum Loop Sound deve avere il loop abilitato nelle Import Options di Godot
(se il formato/importer lo prevede), così il ronzio continua senza interruzioni.

Il ronzio parte quando PowerSystem va ON e si ferma quando va OFF.
