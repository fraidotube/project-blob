# Project Blob

Videogioco FPS 3D goliardico ambientato nella sede aziendale.

## Concept
Un meteorite alieno si schianta nei pressi dell'azienda. Un blob mutageno infetta i dipendenti trasformandoli in creature ostili. Il giocatore deve attraversare l'edificio e riuscire a fuggire.

## Engine
Godot 4.7.2 Stable

## Stato
Bootstrap iniziale del progetto.

## Metodo
Sviluppo secondo contratto operativo SAFE.
